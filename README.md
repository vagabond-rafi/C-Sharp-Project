# Freelancer and Client Management System

A **Freelancer and Client Management System** developed using **C#** to simplify and organize the management of freelance projects, client relationships, contracts, payments, and project progress.

The system provides a structured platform for managing interactions between freelancers and clients, allowing users to maintain contract records, monitor project updates, and keep track of payment information.

## Features

- **Client Management:** Manage client information and maintain client records.
- **Contract Management:** Create, view, update, and manage freelance contracts.
- **Payment Management:** Record and track payment details associated with contracts.
- **Progress Tracking:** Maintain project progress updates and monitor ongoing work.
- **Data Management:** Perform database operations to store, retrieve, update, and delete records.

## Technologies Used

- **Programming Language:** C#
- **Framework:** .NET Framework
- **Database:** Microsoft SQL Server
- **Database Connectivity:** ADO.NET
- **Development Environment:** Visual Studio
